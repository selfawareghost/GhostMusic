Full songs on Ghost

Ghost plays complete songs right here through YouTube's official player. To find each song it needs a free YouTube key from Google. You set this up once; it takes about 5 minutes.

  1. Open console.cloud.google.com, sign in with Google, and create a new project named Ghost.
  2. Go to APIs & Services → Library, search YouTube Data API v3, and click Enable.
  3. Go to APIs & Services → Credentials → Create credentials → API key. Copy the key.
  4. Recommended: click the key, set Application restrictions → Websites to your site address (e.g. https://yourname.github.io/*), and under API restrictions pick YouTube Data API v3.
  5. Paste the key below and press Save & test.

The key is saved only in this browser, never inside the site file, so visitors to your site can't see it. The free allowance finds about 100 new songs a day; songs you've played before don't count again.

Install Ghost on your iPhone. Tap Share then Add to Home Screen.
